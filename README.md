## Project Structure
This repository is structured into directories:

```text
.
├── code/               # All the code for the project, including all explanatory data.
├── data/               # The datasets relating to the project.
├── notes/              # Tracks group developments and decisions.
├── outputs/            # Any and all outputs, this includes graphical plots and creates tables.
└── task_documentation/ # Given documentation to help complete the task.
```

### code/
This directory contain all the code created for this project. 

```text
code/
├── tasks/               # contains all the important code organised in weekly tasks.
└── modeller/            # an experimental package aimed to streamline programming.
```

### data/
This directory contains the datasets relevant to this project.

```text
data/
├── ashford_matches.csv  # Dataset containing the match data of Ashford United.
└── league_players.csv   # Dataset containing various data points on players in the league.
```

### notes/
Contains files tracking team actions.

```text
notes/
├── decision_notes.md  # Table to summaries group meeting and decisions.
└── who_did_what.md   # Table to track member activities.
```


### outputs/
This directory contains all outputs. These could be plots, reusable models or adjusted
datasets.

```text
outputs/
├── diagnostic_reports  # Reports generated to judge a model.
├── examples            # Plots from the `code/modeller/examples/` directory.
├── plots               # Plots from the `code/tasks/` directory.
└── models              # Regression models stored from other outputs.
```

### task_documentation
This directory contains given information, details and advice about the task.
